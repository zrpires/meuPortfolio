## 📌 Sobre o Projeto

Este projeto é a minha vitrine profissional. Muito mais do que um currículo estático, ele foi desenvolvido para demonstrar na prática minhas habilidades com **Front-end**, manipulação de DOM e lógica de programação.

## ✨ Destaques e Funcionalidades

- 🎨 **Design Glassmorphism:** Interface translúcida moderna com um sistema de partículas responsivo ao mouse rodando nativamente no `<canvas>`.
- 💻 **Terminal Interativo:** Um console `bash` funcional embutido na página! Tente digitar comandos como `whoami`, `skills`, `xp` ou `help`.
- 🌐 **Internacionalização (i18n):** Tradução instantânea entre **PT-BR** e **EN-US** sem necessidade de recarregar a página.
- 🕹️ **Easter Eggs:** O site escuta eventos de teclado. Experimente digitar `sith`, `poke` ou `pref` a qualquer momento para ativar animações e efeitos sonoros ocultos.
- 📱 **100% Responsivo:** Adaptado para funcionar perfeitamente em telas *mobile* e *desktop*.
